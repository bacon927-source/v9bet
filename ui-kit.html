V9Bet Mobile web UI kit

The engineering reference for the mobile web UI: how to wire it up, the variables, and every component with its states and markup. Built on Tailwind CSS. The look is the live product (Figma APP-V9Bet-v1); the rules for using it are in the guideline.

Setup · Variables · Page template · Components · Behaviour · Not built yet · Checklist

Setup

Three things make up the kit. Nothing else is needed — there is no component library to install and no web font to load.

FileRole
variables.cssEvery value — colours, type sizes, radii — as CSS variables. The single source of truth; the native app reads the same numbers.
tailwind.config.jsMaps the variables to Tailwind theme keys and defines the component classes in a plugin (addComponents). Tailwind v3 format.
assets/icons/ · assets/social/The icon set (v1's Bold Rounded icons, see Icons) and the official Google / LINE / Zalo marks.

Prototype — CDN

How the pages in this repo run today. The CDN build reads the same config file a real build would, so nothing is defined twice.

<link rel="stylesheet" href="variables.css">
<script src="https://cdn.tailwindcss.com"></script>
<script>var module = {};</script>
<script src="tailwind.config.js"></script>
<script>tailwind.config = module.exports;</script>

Production — build

The CDN script is not for production. Use the Tailwind CLI (or PostCSS) with the same config; neither the config nor the markup needs to change.

/* app.css */
@import "./variables.css";
@tailwind base;
@tailwind components;
@tailwind utilities;
npm install -D tailwindcss@3
npx tailwindcss -c tailwind.config.js -i app.css -o dist/app.css --minify
  • Serve the pages over HTTP. Opened from file://, the CDN script and the config will not load. For a local preview: python3 -m http.server 4599 in the repo root.
  • Dark is the default theme. Light is switched with <html data-theme="light">; do not use the dark: prefix. The light theme is not finished.

Spacing

Six steps, named with Tailwind's own numeric keys (1 = 4, 2 = 8, 3 = 12, 4 = 16, 5 = 20, 8 = 32) — the same names as Figma's spacing/N variables and --space-N. The number is the step, not the pixels. Spacing uses only these six; the other keys are for sizes (theme.spacing), read from variables.css. They work with every spacing utility — gap-, p-, m-, space-y-. Use the step, never gap-[10px].

Icons

One set: v1's Flaticon UIcons Bold Rounded, in assets/icons/. Use <span class="icon icon-close" aria-hidden="true"></span> — 24 on its own, add icon-sm for 16 inside a field. The colour is the text colour (text-*). A button around an icon carries the aria-label and is at least 44 × 44. Class / attributeWhat it does
.fieldWrapper. 60px tall: a 50px box plus 10px above it for the lifted label.

.field > labelMust come directly after the input. Connect them with for / id.

One-time code

.otp

Six cells for the code sent by email or SMS. Type in the first row — it moves on by itself, takes a pasted code, and enables the button at six digits.

We sent a verification code to 091***233

Resend code in 00:32

Invalid code entered

Class / attributeWhat it does
.otpThe row: cells centred, 10px apart. Give it role="group" and an aria-label.
.otp > inputA cell: 42 × 44, radius 12 (rounded-xl), digit 17/22. Outline #4B4B4B while empty, green once it holds a digit, white while focused. Must have placeholder=" ".
data-invalidOn the row: every cell turns red. Put an .error-text directly under the row, 10px below. The button does not change.
inputmode="numeric"On every cell, with pattern="[0-9]*": opens the number pad.
autocomplete="one-time-code"On the first cell only: the phone offers the code from the message. The whole code lands in that cell and the script spreads it out.
  • No maxlength on the cells — it would cut a pasted or autofilled code down to one digit. The script keeps one digit per cell.
  • The blocks on the screen are 30px apart: the message, the cells, the resend line, the button.
  • The timer is bold green with tabular-nums so it does not shift as it counts. When it reaches zero the line becomes a bold green underlined link, Resend code.
  • A rejected code keeps its digits. The red clears on the next keystroke.
  • The cells shrink below 42px only on screens narrower than 332px.

Behaviour

The components are CSS only. State is carried by standard attributes, so the script side stays small and works with any framework.

StateHow to set it
Button enabled / disabledsubmit.disabled = true | false
Selected tabtab.setAttribute("aria-selected", "true")
Tick on / offNative — read input.checked, listen for change
Field label liftedAutomatic, from focus and value
Show / hide a block or a field noteThe hidden attribute
Field invalidinput.setAttribute("aria-invalid", "true") and un-hide its .error-text
Code cell filledAutomatic, from the value
Code rejectedotp.toggleAttribute("data-invalid", true) and un-hide the .error-text under it
// Tabs
const setTab = (mode) => {
  tabPwd.setAttribute('aria-selected', String(mode === 'pwd'));
  tabOtc.setAttribute('aria-selected', String(mode === 'otc'));
  fieldPwd.hidden = mode !== 'pwd';
  hintOtc.hidden = mode !== 'otc';
  submit.textContent = mode === 'pwd' ? 'Log In' : 'Send Code';
};

// The button stays grey until the form can be sent
const sync = () => { submit.disabled = !terms.checked || !email.value.trim(); };
terms.addEventListener('change', sync);
email.addEventListener('input', sync);

// Show / hide password
toggle.addEventListener('click', () => {

// One-time code: one digit per cell, moving on as they arrive
const cells = [...otp.querySelectorAll('input')];
const code = () => cells.map((c) => c.value).join('');
const reject = (on) => {
  otp.toggleAttribute('data-invalid', on);
  otpError.hidden = !on;
};
otp.addEventListener('input', (e) => {
  // Typing, a paste and the phone's autofill all arrive here.
  const from = cells.indexOf(e.target);
  const digits = e.target.value.replace(/\D/g, '').slice(0, cells.length - from);
  e.target.value = '';
  [...digits].forEach((d, i) => { cells[from + i].value = d; });
  if (digits) cells[Math.min(from + digits.length, cells.length - 1)].focus();
  reject(false);
  verify.disabled = code().length < cells.length;
});
otp.addEventListener('keydown', (e) => {
  // Backspace in an empty cell clears the one before it.
  const i = cells.indexOf(e.target);
  if (e.key !== 'Backspace' || e.target.value || i === 0) return;
  cells[i - 1].value = '';
  cells[i - 1].focus();
  verify.disabled = true;
});
// Selecting on focus means typing in a filled cell replaces its digit.
otp.addEventListener('focusin', (e) => e.target.select());
