Setup 八項

The Eight Setup Items
註冊完成後的基本設定。八個項目分三步，但只有第一步真的擋人——後面兩步可以整段跳過。跳過的直接代價只是少拿點數；真正的代價是之後會在某個地方被擋下來，下面逐項列出被擋在哪。
The basic settings after registration. Eight items in three steps, but only the first step actually blocks — the other two can be skipped wholesale. Skipping costs points up front; the real cost arrives later, at the point each item is finally demanded. Every one of those points is listed below.

八個項目，以及跳過之後會在哪裡被擋

The eight items, and where skipping each one catches up with you
#
項目 · Item
狀態
跳過的代價 · What skipping costs
1
幣別
Account currency
必填
只有 VND / THB，設定後鎖定，要改只能找客服。所有存提款、餘額、優惠都掛在它上面，所以不可能延後。
VND or THB only, locked once set — changing it means Live Chat. Every deposit, balance and promotion hangs off it, so it cannot be deferred.
2
個人資料
Personal information
必填
姓名、生日、性別、國籍。收款帳戶的戶名會鎖定成這裡的姓名，所以它必須先存在。KYC 通過後姓名／生日／國籍就不能自己改了。
Name, birthday, gender, nationality. The payout account's holder name is locked to the name here, so this has to exist first. Once KYC passes, name, birthday and nationality can no longer be self-edited.
3
收款帳戶
Bank account / USDT
可跳過
提款時會被擋，而且必須擋在輸入金額之前、直接導回這頁，不能讓人打完金額才失敗。就算當場補，第一次提款到任何帳戶仍要 OTP——等於連過兩關。
Blocked at withdrawal — and the block has to land before the amount is entered, routing back here, never as a failure after typing an amount. Even when added on the spot, a first withdrawal to any account still triggers OTP, so it is two gates in a row.
4
聯絡方式
Contact details
看情況
帳號已有聯絡方式（Email 註冊、Google）→ 這裡是補電話，可跳過。跳過的話 SMS 與社群訊息管道用不了，少一種登入與救回帳號的方式。
帳號沒有聯絡方式（Zalo、沒權限的 LINE）→ 移到 Step 1 必填，沒有 Later。
Account already has a contact (email sign-up, Google) → this adds a phone and is skippable; skipping locks out SMS and social messaging and removes one login and recovery route.
Account has none (Zalo, LINE without the permission) → it moves into Step 1 as required, with no Later link.
5
設定密碼
Set a password
可跳過
不設就不能用密碼登入，但一次性碼、Passkey、社群照常。系統不會透露某個帳號有沒有設密碼——沒設的人用密碼登入一律回 INVALID_CREDENTIALS。沒有 4 位數 PIN，強度不夠。
Without one, password login is unavailable, but one-time code, passkey and social all still work. Whether an account has a password is never revealed — trying one returns a plain INVALID_CREDENTIALS. No 4-digit PIN: not strong enough for an account password.
6
通知
Notification permission
可跳過
系統層權限被拒也沒關係，站內偏好仍然會記錄，之後開權限就會生效。
A denied OS-level permission is fine — in-app preferences are still recorded and take effect if permission is granted later.
7
主題
Theme
可跳過
dark / light / 跟隨系統，預設跟隨系統。語言不在這裡——語言跟著註冊 IP 解析，在到達註冊頁之前就套用好了，之後在 header 切換器或 Settings › Preferences 改。
Dark, light or follow-system, defaulting to follow-system. Language is not here — it is resolved from the registration IP and applied before sign-up is even reached, then changed via the header switcher or Settings › Preferences.
8
訊息管道
Message channel
可跳過
預設 Email（新會員還沒有電話）。SMS 和社群訊息需要先有已驗證的電話，所以跳過項目 4 就等於鎖住這裡的選項。退訂只停行銷訊息——OTP、安全通知、存提款狀態一律照發。
Email by default (a new member has no phone yet). SMS and social messaging require a verified phone, so skipping item 4 locks the options here. Opting out stops marketing only — OTP, security alerts and payment status always send.

項目 4 為什麼會換位置 · Why item 4 moves

判斷依據是 has_verified_contact，不是看用哪種方式註冊。Google 會給已驗證的 email，那種會員不該被再問一次；真正需要補的是 Zalo 和沒拿到 email 權限的 LINE。用帳號狀態判斷，之後 LINE 若申請到 email 權限，會自動換到可跳過那邊，不用改任何畫面。編號維持 4，因為 API 和點數帳本都是用這個編號。
The test is has_verified_contact, not which method was used. Google returns a verified email, so those members should not be asked twice; the ones who genuinely need it are Zalo and LINE without the email permission. Because it keys off account state, LINE moves to the skippable side on its own if the permission is granted — with no screen changes. It keeps the number 4, since the API and the points ledger reference it.

跳過的代價其實不是點數

Points are not what skipping actually costs
每項 +10 點，八項全做完再加 20 點，共 100 點。跳過的直接後果只是少拿那 10 點，沒有別的懲罰，也不會被催。但真正的代價在後面：跳過項目 3 的人會在提款時撞牆，跳過項目 4 的人連帶失去項目 8 的選項。設計這份清單時要記得——放進 Step 2 就等於這件事可以永遠不做。（Face ID / Passkey 原本是項目 4，09-20 整項移出 setup：安全方式放 Settings › Security，見 security-methods-wireframe.html。）
Each item is +10, with a 20-point bonus for finishing all eight — 100 total. The immediate consequence of skipping is only those 10 points; nothing else is withheld and nobody is nagged. The real cost lands later: skipping item 3 means hitting a wall at withdrawal, and skipping item 4 takes item 8's options with it. Worth remembering when deciding where an item goes — anything placed in Step 2 is something a member may simply never do.
